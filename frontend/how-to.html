VERSÃO NÃO TÉCNICA

Veja o trabalho acontecendo

O AI Operations Room organiza as sessões do Gemini (agy) em uma visão simples. Cada projeto aparece como uma sala e cada agente aparece trabalhando, aguardando ou concluindo uma tarefa.

Passos rápidos

  1. Abra a página Projetos.
  2. Cadastre a pasta do projeto que você abre no terminal/VS Code.
  3. Trabalhe normalmente no seu client agy / Gemini.
  4. Volte ao Escritório para acompanhar as sessões em tempo real.

O status é atualizado automaticamente a cada 4 segundos.

VERSÃO TÉCNICA

Como a associação funciona

O Operations Room sincroniza eventos e sessões automaticamente a partir do banco e presença locais do Gemini (~/.gemini) ou via hooks opcionais. Cada sessão informa o caminho de trabalho. O Operations Room compara esse caminho com as pastas cadastradas e aplica o projeto cujo caminho for mais específico.

Configuração

  1. Inicie o servidor com uv run python -m backend.cli serve.
  2. Mapeie as raízes dos repositórios em Projetos.
  3. Use SUGESTAO_DE_AGENTES.md como referência de agentes especializados para suas tarefas.

O arquivo SUGESTAO_DE_AGENTES.md fica na raiz do repositório e reúne sugestões de papéis para subagentes.
